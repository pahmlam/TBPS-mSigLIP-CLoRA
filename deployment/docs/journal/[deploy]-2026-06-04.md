## 3. Chẩn đoán trong ngày

- Tăng calibration từ 500 lên 2,000 không sửa được QDQ fidelity.
- Đổi activation dtype từ INT8 sang INT16 chỉ cải thiện nhẹ, vẫn thấp rất xa gate `0.95`.
- Đổi range scheme sang `min_max` không cải thiện; `j5m4vjxd5` còn thấp hơn nhẹ so với W8A8 default.
- Lite-MP default cải thiện lên `cosine_l2_mean = 0.1906`, nhưng vẫn fail nặng so với gate `0.95`.
- PTQ đang làm lệch hướng embedding, không chỉ lệch scale output.
- Không được compile/link QNN cho `jgomex415`, `jp2j31dm5`, `j5m4vjxd5`, hoặc `jgl7en9l5`.

## 5. Command cho việc chưa làm

### Lite-MP 30% INT16

```bash
venv/bin/python deployment/scripts/qnn/submit_qaihub_quantize_compile.py \
  --model artifacts/deployment/exports/exported_model/vision_onnx \
  --calibration-data d7jzjy1m2 \
  --weights-dtype int8 \
  --activations-dtype int8 \
  --quantize-options="--lite_mp percentage=30;override_qtype=int16" \
  --name msiglip-vision-lite-mp-30-int16-calib2000-qonly \
  --wait \
  --quantize-only \
  --download-quantized artifacts/deployment/runtime/ptq_experiments/calib2000_lite_mp_30_int16/qdq_onnx
```
