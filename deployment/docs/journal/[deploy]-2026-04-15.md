# [Deploy] 2026-04-15 - Khảo sát AI Hub compile cho vision encoder

> **Ngày:** 2026-04-15

## 1. Tóm tắt quyết định

Các thử nghiệm trong ngày xác nhận bốn luật quan trọng cho AI Hub / QNN HTP:

- Upload ONNX có external weights phải upload **directory**, không upload file `.onnx` rời.
- `qnn_context_binary` không chấp nhận dynamic input shape; vision input phải static `1x3x256x256`.
- `--input_specs` của `qai-hub` phải là Python dict literal, không phải chuỗi colon-separated.
- HTP V68 trên QCS6490 reject mọi floating-point I/O ở boundary, gồm cả FP32 và FP16; local FP16 ONNX hữu ích cho debug/GPU nhưng chưa đủ cho HTP.

## 2. Bối cảnh

Vision encoder đã export sang ONNX với external data. Mục tiêu là compile graph này bằng Qualcomm AI Hub thành QNN context binary chạy trên RB3 Gen2. Các thử nghiệm trong ngày chủ yếu là compile-path exploration, chưa phải fidelity hoặc retrieval benchmark.

## 4. Command / lesson đã migrate

Command local FP16 ONNX conversion hữu ích cho debug hoặc GPU fallback:

```bash
python deployment/scripts/onnx/to_fp16.py \
  --input artifacts/deployment/exports/msiglip_lora/vision_onnx \
  --output artifacts/deployment/exports/msiglip_lora/vision_onnx_fp16
```

Command mẫu đúng format cho static input specs:

```bash
qai-hub submit-compile-job \
  --model artifacts/deployment/exports/msiglip_lora/vision_onnx/ \
  --device "Dragonwing RB3 Gen 2 Vision Kit" \
  --compile_options " --target_runtime qnn_context_binary" \
  --input_specs '{"image": ((1, 3, 256, 256), "float32")}' \
  --wait
```

Command này chỉ đúng về syntax/shape. Nó vẫn fail trên HTP nếu I/O còn floating-point.

## 5. Chẩn đoán

- Lỗi upload đầu tiên nằm ở artifact format: ONNX external data cần upload nguyên directory.
- Lỗi sau đó nằm ở shape: QNN context binary path cần static shape.
- Các thử nghiệm FP32/FP16 đều chứng minh HTP không nhận floating-point I/O ở boundary.
- `--quantize_io` không phải compile option hợp lệ trong flow CLI cũ; không nên dựa vào flag này.
- Không thể ép dtype bằng `input_specs` nếu ONNX graph khai báo dtype khác.
