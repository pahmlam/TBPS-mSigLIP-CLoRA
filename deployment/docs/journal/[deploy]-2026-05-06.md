# [Deploy] 2026-05-06 - INT8 compile path và dummy calibration

> **Ngày:** 2026-05-06  
> **Thiết bị / Runtime:** Qualcomm AI Hub / QNN HTP / RB3 Gen2 Vision Kit  
> **Model / Artifact nguồn:** `vision_onnx/` FP32, target `qnn_context_binary`  
> **Mục tiêu:** Kiểm tra INT8 quantization path cho HTP và xác định liệu QNN context binary có thể tạo được khi I/O không bị preserve float.  
> **Trạng thái cuối ngày:** PARTIAL

---

## 1. Tóm tắt quyết định

Ngày này xác nhận root cause của các compile failure trước đó: HTP cần I/O integer, nhưng compile flow có thể tự preserve I/O float nếu dùng sai path/flag. Khi không preserve floating-point I/O, AI Hub tạo được QNN context binary INT8 cho vision encoder.

Kết quả `jgkr7qwn5` chỉ là **compile-path sanity** với dummy calibration. Nó chứng minh HTP context binary có thể được tạo, nhưng không chứng minh fidelity hoặc retrieval accuracy.

## 2. Bối cảnh

Các thử nghiệm 2026-04-15 đã loại bỏ FP32/FP16 I/O cho HTP. Bước tiếp theo là thử INT8 quantization và xem AI Hub có tạo context binary được không.

## 4. Command / lesson đã migrate

Command compile-path sanity đã tạo được binary:

```bash
qai-hub submit-compile-job \
  --model artifacts/deployment/exports/msiglip_lora/vision_onnx/ \
  --device "Dragonwing RB3 Gen 2 Vision Kit" \
  --compile_options " --target_runtime qnn_context_binary --quantize_full_type int8" \
  --input_specs '{"image": ((1, 3, 256, 256), "float32")}' \
  --calibration_data none \
  --name "mSigLIP-vision-int8-dummy" \
  --wait
```

Ghi chú: `--quantize_full_type` và `--target_runtime qnn_context_binary` là deprecated path. Command này giữ lại để hiểu lịch sử và làm compile-path sanity, không dùng làm production path.

## 5. Chẩn đoán

- `jpyvrrv7p` cho thấy `--quantize_full_type int8` có thể vẫn đi kèm `--preserve_io_datatype image output_0`, làm I/O giữ FP32 và bị HTP reject.
- `jgkr7qwn5` cho thấy khi I/O được quantize cùng internals, QNN context binary cho HTP V68 có thể tạo được.
- Dummy calibration chỉ dùng để xác minh compile/runtime path; embedding sinh ra từ binary này không được xem là đúng.
