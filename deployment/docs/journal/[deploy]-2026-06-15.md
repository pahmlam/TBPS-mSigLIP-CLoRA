## 5. Quyết định: implement rotation (QuaRot/SliceGPT-style) trên PyTorch

User còn ~1 tháng → chọn hướng này (thay vì FP16). Làm trên PyTorch (truy cập module theo tên), rồi export opset-20 → quantize W8A8.

### Cấu trúc model (đã inspect)

- `backbone.vision_model` = SiglipVisionTransformer: `embeddings` (patch_embedding Conv2d + position_embedding) → `encoder.layers.0..11` (mỗi layer: `layer_norm1`→`self_attn`(q/k/v/o proj)→residual, `layer_norm2`→`mlp`(fc1/gelu/fc2)→residual) → `post_layernorm` → `head` (MultiheadAttentionPoolingHead: attention + layernorm + mlp).
- LayerNorm đều affine, shape (768,). Residual dim = 768.
- LƯU Ý: TBPS có cả `backbone.vision_model` lẫn top-level `vision_model`; cần xác nhận `encode_image` dùng cái nào trước khi sửa.

### Công thức (recipe)

**Phase A — LayerNorm → RMSNorm (output-invariant):**
1. Với mỗi LN(γ,β) feeding consumer linear W(+b): fold γ vào W (`W·diag(γ)`), fold β vào bias (`b + W·β`); set LN affine = identity.
2. Làm residual mean-zero: fold `M = I − (1/d)·11ᵀ` vào MỌI weight ghi vào residual (embeddings out, mỗi o_proj, mỗi fc2): `W_out → M·W_out`, `b_out → M·b_out`. Vì LN trừ mean nên `LN(Mx)=LN(x)` → bất biến. Sau bước này LN = RMSNorm.

**Phase B — rotate residual bằng Q trực giao (768×768):**
- Writers (embeddings out, o_proj, fc2): `W_out → Q·W_out`, `b_out → Q·b_out`.
- Readers (q/k/v/fc1 qua LN đã fold γ; head K/V qua post_layernorm): `W_in → W_in·Qᵀ`.
- RMSNorm(Qx)=Q·RMSNorm(x) nên xoay đi xuyên norm. Q dùng random orthogonal (offline fold, không cần fast Hadamard; không thêm op runtime).
- Head: chỉ cần fold Qᵀ vào K/V proj của `head.attention` (probe/query là learned, không đổi). Có thể localize rotation trong encoder rồi để post_layernorm+head tự nhận lại nhờ fold Qᵀ.

## 9. M3 FAIL (`0.16`) → root cause RMSNorm + FIX (mean-preserving rotation)

- M3 W8A8 trên rotated (job `jp48z6o2g`): compare vs PyTorch gốc = `cosine_l2_mean 0.162` — gần như không hơn W8A8 chưa xoay (`0.14`).
- Surgery decompose: `all_activations_float = 0.978` (weights OK), `all_weights_float = 0.162` → **lỗi 100% ở ACTIVATION** dù residual concentration đã `220x→10x`.
- Đo trực tiếp QDQ: top activation tensors theo range đều là **`Pow` output** (RMSNorm x²), abs_max tới 918; top-30 toàn `Pow/ReduceMean/Add`.
- **ROOT CAUSE:** đổi LayerNorm → RMSNorm decomposed đã **phơi bày nội bộ normalization (`Pow/ReduceMean/Div`) ra cho per-tensor quant.** Model gốc dùng **LayerNorm FUSED** (HTP tính nội bộ, chỉ quantize I/O). Rotation làm đúng (residual diffuse) nhưng tác dụng phụ "phải RMSNorm" tạo bệnh mới. (Lập luận "ReduceMean trung bình hóa nên ổn" ở M2 SAI.)

### FIX: mean-preserving rotation → giữ LayerNorm fused

- Dùng **Q bảo toàn mean** (`Q·1 = 1`): xoay random trong không gian con trực giao với vector `1`, giữ nguyên chiều mean. Khi đó `mean(Qx)=mean(x)`, `std(Qx)=std(x)` → **identity-affine LayerNorm commute với Q** → KHÔNG cần RMSNorm.
- Sửa `rotate_vision_encoder.py`:
  - `_mean_preserving_orthogonal(dim,seed)`: `Q = U·blockdiag(1,Rc)·Uᵀ`, `U[:,0]=1/√d`.
  - `phase_a`: fold γ/β vào readers + `_set_ln_identity` (giữ LayerNorm op, KHÔNG replace RMSNorm, KHÔNG fold M).
  - `phase_b`: dùng Q mean-preserving.
  - `load_rotated_model`: đơn giản lại (LayerNorm chuẩn → `_load_pytorch_model` load đúng; bỏ swap RMSNorm).
- **Validate local (đã chạy):** invariance Phase A & B `1.0` (min `0.99999988`); Q orthogonal `3e-15`, `Q·1=1` err `1e-14`; reload `1.0`; **residual concentration `252x → 5.3x`** (tốt hơn cả lần RMSNorm). Đã ghi đè `exported_model_rotated` bằng bản đúng.

## 14. R2 (QuaRot head_dim Hadamard trên attention V/O) — KHÔNG cải thiện, gate vẫn FAIL

> Thử lever rẻ nhất trước QAT: xoay value/attention-output path. Local M1/M2 free; M3 = 1 job AI Hub.

### Implement (local, free)

- `rotate_vision_encoder.py` thêm **phase_c (R2)**: block-diagonal Hadamard `H` (head_dim=64, 12 heads) fold offline vào `v_proj` (output, `BDᵀ`) + `out_proj` (input, `BD`). Output-invariant: `outₕ@H` triệt tiêu `(W_oₕ@H)`; softmax không phụ thuộc V. **Không op runtime** → v68-safe (khác R3/R4).
- R2 tác động trục **head_dim**; rotation residual (phase_b) tác động trục **embed_dim** → fold độc lập.
- Output dir mới `exported_model_rotated_r2` (giữ bản 0.90 cũ làm đối chứng).
- **M1 gate PASS:** Phase C invariance cosine `1.0` (min `0.99999988`), Hadamard orthogonality err `0.0`.
- **M2 gate PASS:** ONNX opset-20 op counts `Gelu=13, LayerNormalization=26, Pow=0`; static control vs PyTorch `1.0000`.
